# 实现计划：AgentRAG EvalKit

## 概述

本计划基于《AgentRAG EvalKit-需求文档》和《AgentRAG EvalKit-系统架构文档》，将当前以 Mock Adapter、内存存储和只读 Dashboard 为主的作品集 Demo，逐步补齐为能够配置并连接真实 HTTP、LangGraph、Dify、RAGFlow Agent/RAG，导入评测集、异步执行评测、查看 Trace、管理 Badcase 并进行版本回归的可操作评测平台。

## 注意事项

- 标记为 * 的任务属于可选增强项，不阻塞首个可用版本交付。
- 每个关键任务均引用需求编号或架构章节，以保证从需求、设计、实现到验收的可追溯性。
- 检查点用于增量验证；完成一个阶段后应先运行对应测试并确认兼容性，再进入下一阶段。
- 属性测试用于验证在大量组合输入下始终成立的不变量；单元测试验证单个函数或组件，集成测试验证数据库、队列、Adapter、API 和 UI 之间的协作。
- 本文中的勾选框表示任务已纳入实现计划，不表示当前代码已经完成。下一步实施时应根据实际进度维护状态。
